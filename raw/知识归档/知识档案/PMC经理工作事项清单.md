# PMC 经理工作事项清单

> **状态**：unreviewed（待人工审核）
> **来源**：[[raw/收件箱/PMC经理工作事项.xlsx]]（10 个工作表，逐表提取）
> **主表**：`03-行事历清单` —— 表头即「**PMC 经理工作事项**」，按 **一级模块 × 事项 × 类别 × 周期 × 协同方 × 工作内容及标准 × 参考制度 × 系统** 八列组织
> **价值定位**：这是 **PMC 经理岗位的"日常动作全集"** —— 与 [[wiki/任职资格/PMC经理能力模型]] 的「10 项主要职责 / 26 项要素」（**标准层**）互为表里，本档是**实际怎么干**（执行层）。
> ⚠️ 本档**未收录**原表「账号+地址」工作表中的网站登录密码（按「不在笔记中存储敏感凭证」规则剔除），详见附录 G。

## 核心要点

- **八个一级模块**：产品档案管理 / 采购订单闭环 / 参与日常库存管理 / 参与供方管理 / 参与供方质量管理 / 参与供方成本管理 / 供方合同及票务 / 周例会 —— 共 **34 条事项**。
- **按周期分层**：日（1 条）→ 周（2 条 + 每周二/三例行的 4 条）→ 月（3 条）→ 季（2 条）→ 年（1 条）→ 不定时/临时（其余）。**大部分事项无固定周期，属"不定时常规"**。
- **两条主线贯穿**：① **采购订单闭环**（下单 → 物流 → 交期 → 付款 → 三单相符 → 到货 → 异常中止）；② **库存保交付防滞销**（日监控 → 清库协同 → 大单发货 → 每日缺货处理）。
- **少数"重点工作"标记**（4 条，是考核权重最高的）：系统创建新品档案、发起采购订单、三单相符、监控日常库存保交付防滞销、日常缺货处理（共 5 处标记，含 1 条跨模块）。
- **协同面极广**：供开部 / 仓储管理部 / 财务部 / 质量部 / CBG / 客服部 / 分销部 / 产品市场部 / 供应商 / 物流货代 / 数字化组 —— **PMC 是供应链内部的"接口人"角色**。
- **系统工具栈**：**管家**（主系统，出现频次最高）、内部系统、阿里 1688 平台、企业微信、钉钉、BI 报表、物流查询网站。
- ⭐ **对认证的直接意义**：这 34 条就是认证材料的**案例素材池** —— 每条都能对应到 26 项要素里的某一项；「三单相符」「缺货处理」「异常中止退款」这类**跨部门争议场景**正是"复杂案例"的最佳取材处。

**编制全流程**

| 阶段 | 要点 |
|------|------|
| **1 立项** | ① 岗位说明书的显著意义/价值：指导任职人员掌握岗位信息、指导内部人才"**选用育留出**"、**规避劳务风险**；② 公司层面定调提高重视度；③ 做好岗位分析，让业务和 HR 认知角度与立场相对同频 |
| **2 分析** | 方法：观察法、面谈法、调查问卷法、**关键时间分析法**、资料分析法。步骤：公司战略剖析 → 部门职责梳理 → 职能模块梳理 → 职能业务流梳理 → **岗位职责梳理** |

| **4 应用** | 招聘（录用直接依据，需员工签收）/ 工作指导管理 / 激励晋升 / 培养发展 / 换岗汰换 |
| **5 管理** | 纳入职位管理，合规性民主程序（发文 + 宣导会，或内部平台邮件、OA 文件公示） |

**常见编制误区 8 条（原文照录）**

1. 脱离业务现实，闭门造车，无法落地
2. 业务部门和人资行政部协同认知不同频
3. 只针对当下任职者，而不是岗位本身，客观性、前瞻性不足
4. 内容贪多，在必要性和重要性上未能平衡
5. 工作职责描述过于笼统、模糊，无法应用
6. 格式不统一，难以同纬度管理
7. 只写不用，没有共创同频，遭受质疑未及时进行共创调整
8. 一劳永逸、一成不变，跟不上业务发展

**审核常见问题三类（3.3）**：**职能交叉**（同层次部门职责有较大交叉）/ **职责缺失**（同层次部门职责有缺失，出现"有问题两个部门都不负责任"）/ **职责错位**（由甲部门负责的职责现在由乙部门负责）。
**三级审核**：初审（岗位上级，重点确认职能协同）→ 二审（岗位部门会审，重点确认跨职能协同）→ 终审（部门 + 人力资源部，重点确认全工作流覆盖及规范性）。

**五个概念的异同点（7.）—— 原文照录**

| 概念 | 原文定义 |
|------|---------|
| **任职资格** | 完成工作目标所需要的必备条件，通常侧重**显性特质**（经验、学历等），通常是**上岗必备条件** |
| **胜任力素质** | 区分岗位绩效高低的依据，指将**卓越员工和普通员工区分开来**的个人深层次特征，包括动机、特质、态度或价值等，更关注**隐性能力**；更多用作**培养发展**的依据 |
| **岗位说明书** | 据某项职务工作的物质和环境特点，对工作岗位相关因素进行的详细说明。通常包含"任职资格"，可含"胜任力素质" |
| **招聘 JD** | 粗暴理解为：以岗位说明书为依据，为吸引应聘者的岗位"广告"式呈现 |
| **人才画像** | 粗暴理解为："你以为目标群体现状或未来最好的样子"，通常包含任职资格和胜任力素质等 |
