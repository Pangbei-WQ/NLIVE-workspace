# 供应链的三道防线（第一篇 第1-17页）
- 1. 供应链管理的本质
  - 供应链 = 计划 + 三大执行职能
    - 采购（买进来）
    - 生产（增值）
    - 物流（配送）
  - 核心关系：计划驱动执行
    - 计划 = 想到（引擎）
    - 执行 = 做到
  - 核心金句："计划想不到，执行就很难做到"
- 2. 问题的根源
  - 表面现象（三大表现）
    - 成本做不下来
    - 交付做不上去
    - 库存周转太慢
  - 深层诊断：根源在计划，而非执行
  - 改善方向：改善计划以改善执行
- 3. 为什么要建三道防线
  - 根本前提
    - "所有的预测都是错的"
    - 只能尽力做准确度最高的错误预测
  - 逻辑推导：预测不准 → 不能只靠第一道防线 → 必须层层设防
  - 堤坝比喻（三层覆盖）
    - 第一道堤坝（需求预测）→ 拦住80%左右
    - 第二道堤坝（库存计划）→ 拦住10%~20%
    - 第三道堤坝（供应链执行）→ 对付5%~10%
- 4. 三道防线的功能分工
  - 第一道防线：需求预测 → 提高首发命中率
  - 第二道防线：库存计划 → 预测错了，设安全库存/产能应对
  - 第三道防线：供应链执行 → 预测失败+安全库存不够，靠执行能力弥补
- 5. 为什么要关注三道防线（成本视角）
  - 显性成本：采购成本（人们习惯性关注）
  - 隐形成本（三道防线直接影响）
    - 运营成本
    - 库存成本
- 6. 核心结论
  - 首要任务：建好前两道堤坝（尤其第一道不能垮）
  - 整体逻辑链：问题根源在计划 → 预测永远不准 → 必须构建三道防线 → 降低运营和库存成本
