# PMC经理 - 职位说明书

## 基本信息

| 字段 | 内容 |
|------|------|
| 职位名称 | PMC经理 |
| 职位类别 | 专业 |
| 所属一级部门 | SCBG |
| 所属二级部门 | 供应链中心 |
| 直接上级 | 供应链中心总经理 |
| 业务上级 | SCC委员会 |

## 职位目标

**统筹 OTD（订单准时交付）全流程**，实现供应链端到端实时拉通，对供应约束进行预算管控和全过程统筹，完成订单高效交付、库存周转优化、供应链协同顺畅的核心目标。

## 汇报关系

```
供应链中心总经理
    └── PMC经理  ← 当前位置
            ├── PMC专员
            ├── 供应计划专员
            ├── 计划员
            └── 跟单专员
```

## 主要职责（10项）

| 序号 | 职责描述 | 核心能力维度 |
|------|---------|------------|
| 1 | 滚动计划形成：根据部门GSA与绩效方案，负责个人PBC目标的制定、执行与复盘，达成个人绩效，并根据销售预测、订单需求和阶段节奏，形成滚动需求计划和重点资源排布建议，同步围绕 OTD 项目节点维护需求版本、齐套状态、产能风险、里程碑和复盘记录。 | 业务经营 |
| 2 | 生产物料计划：制定生产计划、物料计划和出货节奏，确保关键订单和重点 SKU 有序推进。 | 协同推进 |
| 3 | 齐套缺料跟踪：跟踪物料齐套、关键缺料和在制状态，提前识别影响交付的供给风险。 | 风险控制 |
| 4 | 排产交付平衡：在产能、交期、优先级和资源冲突场景下进行排产与交付平衡，明确取舍逻辑和升级路径。 | 专业支持 |
| 5 | 重点订单监控：监控重点 SKU、重点订单、平台活动节点、重点战役备货和异常波动。 | 风险控制 |
| 6 | 供给信息协同：拉通供开、采购、制造、仓储、质量和交付等角色，推动计划与供给信息同步、节点对齐和问题闭环。 | 协同推进 |
| 7 | 异常升级机制：建立插单、急单、变更单和异常升级机制，减少计划失真、返工和节奏断档。 | 机制流程 |
| 8 | 计划看板数智化：推动计划看板、缺料预警、变更跟踪、在制状态同步和异常归类等动作数据化、规则化和自动化。 | 数据复盘 |
| 9 | 排程建议校验：对系统或 AI / skill 工作流生成的需求变化、缺料风险、排程冲突和资源平衡建议进行人工校验。 | 机制流程 |
| 10 | 计划方法沉淀：沉淀滚动计划方法、排程模板、异常案例和跨部门协同清单。 | 组织管理 |

### 能力维度分布

- **业务运营**：①计划体系形成、⑨排程节拍校核
- **协同推进**：②上下级计划制定、⑥信息协同
- **风险控制**：③缺料跟进、⑤重点订单管控、⑦异常管控
- **专业支撑**：④产能交期平衡
- **数据改善**：⑧计划数字化
- **组织提升**：⑩计划模板沉淀
