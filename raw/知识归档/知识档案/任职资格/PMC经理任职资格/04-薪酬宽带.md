# PMC经理 - 薪酬宽带

## 薪资结构

| 评定 | 标准描述 | 职等 | 职级 | 基本薪资 | 绩效基数 | 绩效工资(×20%) | 总计 |
|------|---------|------|------|---------|---------|---------------|------|
|  | 特征 | | 职等 | 工资 | 等差 | 绩效奖金基数=工资*20% | 小计 |
|  | 具备国内外行业影响力 | | P15 | 17000 | 1400 | 3400 | 20400 |
|  | 多系统精通，例如PBG，SCBG等两个及以上系统全模块精通 | | P13 | 14250 | 950 | 2850 | 17100 |
|  | 单系统（全模块）精通，例如SCBG全模块精通 | | P10 | 11450 | 900 | 2290 | 13740 |
|  | 多模块精通：主导成功/创新做过XXX，例如SCBG的供开、交付等两个及以上模块精通 | | P7 | 8700 | 600 | 1740 | 10440 |
|  | 单模块精通，涉及多模块：独立重复地完成工作 | | P4 | 6850 | 450 | 1370 | 8220 |
|  | 单模块涉及：新进入这个职位，无法独立工作，必须上级指导 | | P2 | 5900 | 450 | 1180 | 7080 |

## 薪资说明

- **绩效工资 = 基本薪资 × 20%**
- **总计 = 基本薪资 + 绩效工资**
- 职等内部根据能力评定期望值，调薪参考对应职级区间

## 评定等级释义

| 评定 | 含义 |
|------|------|
| 特 | 具备战略性行业影响力，跨组织拉通 |
| 优 | 精通系统全模块，跨BG/SCBG打通 |
| 良 | 掌握本模块核心能力，独立高效完成 |
| 中 | 基本胜任岗位，需辅导跟进 |
| 差 | 未达岗位要求，需改进计划 |
