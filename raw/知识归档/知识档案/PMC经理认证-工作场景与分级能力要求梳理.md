# PMC 经理认证｜工作场景与分级能力要求梳理会

> **状态**：unreviewed（待人工审核）
> **来源**：[[raw/收件箱/export_1788273777161.md]]（会议语音转写原稿，约 33 分钟）
> **会议性质**：认证材料框架**同频会**——组织者把已梳理好的「十大工作场景 + 一~四级能力要求 + 三级样例」摆出来，让被认证者逐条对照自己实际做的事，确认契合度、补充遗漏点。
> ⚠️ 转写为人名/术语识别结果，可能不准（人名以职能指代为主）。

## 核心要点

- **认证材料三件套**是本轮的核心成果物：① 十大工作场景（含场景定义）② 每个场景拆到一~四级的能力要求 ③ 三级样例（原文 → 员工化解读 → 考察点 → 案例指引 → 真实案例）。
- **不必逐条讲 26 项**：三级共 26 项要素（素质能力 + 知识技能 + 行为标准），**一个案例可以覆盖多项**，准备 3 个案例覆盖大部分要素即可，无需逐条答辩。
- **案例统一结构**：背景 → 动作 → 措施 → 结果 → 影响。先讲完整业务案例，再回头说明它体现了哪几项能力。
- **知识技能不考试**，同样走案例形式体现。
- **证据材料**：聊天记录截图 + 文件超链接；建议单独辟一个"附件区"，并做成**证据清单并排序**。
- **佐证材料找不到时**可请部门长作证（原话：部门长可以参与帮忙作证）；**近一年**的证据（去年下半年起）一般都可用。
- **预认证**（8 月第一批）：只走流程、结果不作数，自愿参加，用来摸清现场提问方式；正式认证会**录像**，优秀案例会被放进公司资料库作范本。
- **评委由 EMT 组成**（转写提及若干人名，语音识别不准，待核）。
- 本轮公司重点输出的**三个职位**：运营经理、产品经理、PMC 经理。
- **争议未决**：认证是否要求"跨界"（且跨界要求与薪资条款写在一起）——公司层面尚未确认，待反馈。
- 现场最大摩擦点：**梳理出的场景与实际职责边界对不上**（备货计划归属、清库消化/补货节奏调整/库存健康监控实际由他人主导、空运/货代场景部分人从未接触）。

## 详细内容

### 1. 成果物一：十大工作场景

- **场景定义**由组织者**用 AI 辅助生成**（"我结合这个工作场景自己用 AI 的形式去做出输出的"）。
- **日常工作事例**摘自 **PMC 经理新人培训表单**里的职责内容。
- 用途说明（原话）：

  > 📌 "这个场景的话，是只是说作为参考。如果你们有业务场景，有更好的工作场景，你们也可以用自己的。"

- 输出形态：先出**最重要的前十项**，会上再征集"还有哪些重要的可以加进来"，加进来后组织者再补充场景定义。

### 2. 成果物二：一~四级能力要求拆解

- 组织者按场景逐项标注：做这件事**可以匹配到一级 / 二级 / 三级 / 四级**的哪一档能力。
- 目的（原话）：

  > 📌 "方便大家去看清楚，你做这个事项，它是可以匹配到一级能力、还是二级能力、还是三级、四级能力。"
  > 📌 "你们也可以结合自己目前的工作的这种场景……看能匹配到几级。因为这个案例是要切合实际。"

- 会上还演示了一份**"边界"对照**，让被认证者直观看到等级之间的区别（详见 [[raw/知识归档/知识档案/认证材料打磨-二三级边界与案例讲法.md|二三级边界专题]]）。

### 3. 成果物三：三级样例的结构

样例按**五段式**组织（会上明确"前面都是原文"）：

| 段落 | 内容 | 说明 |
|------|------|------|
| ① 任职资格原文 | 素质能力 / 知识技能 / 行为标准 | 原文照搬 |
| ② 员工化解读 | 把原文翻译成员工能懂的话 | 便于对号入座 |
| ③ 考察点 | 推测评委可能考察的维度 | 组织者强调：**只是推测**，不等于现场问题 |
| ④ 案例指引 | 给出写案例的结构 | 背景 / 动作 / 措施 / 结果 / 影响 |
| ⑤ 真实业务案例 | 一个完整实例 | 让被认证者看懂"怎么套" |

> 📌 关于 ③ 的边界（组织者原话）："这里只是有一个考察点的参考的维度，他可能也没有办法具体到到时候认证的时候会问哪些问题……只能说他结合这一项任职资格原文，我们以这种推测一下，面试官可能会考察哪些内容。"

### 4. 认证规则与操作细节（会上一手信息）

**关于 26 项要素**
- 三级合计 **26 项**（素质能力 + 知识技能 + 行为标准）。
- 原话："26 项是不是都要全讲？能不能一个案例它覆盖到好几项？这种的话问过了，**可以的**。你只输出了三个案例，但你的三个案例已经涵盖了这里边大部分的知识、技能、素质能力和行为标准，这种的话就是可行的。"

**关于讲法**
- 一种讲法：把场景案例全部讲完，再针对每一项说明"我的以下几个动作体现了哪项能力"。
- 组织者补充：**讲法尚未最终确认**，"大家也可以结合自己想讲的这种方式去讲"。

**关于证据材料**
- 形式：聊天记录截图（"你把那一项单独截出来"）+ 文件超链接。
- 有文件的话"就是超链接过去的文件"。
- 组织者建议**不全量呈现证据，只放重点项**。

**关于佐证缺失**
- 原话："如果你们没有涉及的话就不写就可以了"；"时间那么久，可能有些佐证材料没有。没有的话，部门长可以参与，可以帮忙去作证。"

**关于时间范围**
- 原话："去年的可能去年下半年到现在的可能都可以作为证据，**近一年的应该都是没有问题**。"

**关于预认证与正式认证**
- 8 月第一批预认证：**走一遍流程，结果不作为真实考核结果**，自愿报名。
- 预认证现场情形（当时）**尚不清楚**是否可旁听；评委由 EMT 担任。
- 正式认证**会录像**；表现好、可作范本的优秀案例会被放进公司资料库，大家都能看。

**关于重点职位与跨界**
- 本轮梳理三个职位：**运营经理**（对应部门）、**产品经理**（PPT 侧）、**PMC 经理**（本侧）。
- 待决争议：**跨职位/跨业务线是否强制要求**。有参会者发现"四个版本里并没有体现这个要求"，但它被写进了薪资条款里；组织者回应"等公司层面的反馈"。
- 已有口径：**水单不算跨界**（因为本身都做订单）。

### 5. 现场对照：场景与实际职责的出入

这一节是本会最有价值的部分——梳理出的场景与参会者实际在做的事**对不齐**，逐条列出：

| 场景项 | 参会者反馈 | 处理建议 |
|--------|-----------|----------|
| **备货计划**（算不算"交付"） | 分时间/业务线才能定：百货平时不细管；学生季这类"战役"由江苏侧做备货；英式做月度计划 | 按业务线分别表述 |
| **清库消化** | 实际主要**由他人推动**，我们只是在项目里，"给我们安排的事情什么都没做" | 没实际做过的**不写** |
| **补货节奏调整** | 有自己的补货节奏没问题，但"调整"这一动作是**别人在做**，我们只执行/被问原因 | 同上，或换成实际做过的项 |
| **库存健康监控** | 有涉及（清库消化 / 补货节奏调整属其下） | 保留，但只讲自己做的部分 |
| **重点订单空运/陆运/货代分批方案** | 部分人**从未走过空运**（只走陆运） | 可用物流专线/快递/专车等自己真实走过的渠道代入 |
| **周会复盘 / 方法沉淀** | 周会有在做总结，但不是每次都做；方法沉淀可以拿 SOP 出来 | 可以认；SOP 作为证据 |

> 📌 组织者给的通用解法："他这里边有一些场景，如果你们没有涉及的话就不写就可以了。"
> 📌 另一条通用提醒："**不要把没做过的事写成做过**"，因为评委现场会追问细节（参见 [[raw/知识归档/知识档案/认证问答-职责本质理解与评委追问应对.md|职责本质理解]]）。

### 6. 会上的即时疑问与答复

- **Q：评委一定会问的必答题有没有？** → A：没有固定题库，只有基于任职资格原文推测的"考察点参考维度"。
- **Q：认证是单人面对一个评委，还是可以旁听？** → A：预认证情况当时未定；评委是 EMT。
- **Q：认证输出要求会不会变？** → A："认证输出要求也是可以变的，这个也是参考的"，结合 PMC 经理工作职责内容输出，**都可以调**。
- **Q：能不能从入职到现在去挖案例？** → A：建议以**近一年**为主。
- **Q：既然在认证二级，还要不要划二三级边界？** → A：要，**站在评委视角**——评委可能觉得你只到一级，把你跨到一级去（同一问题在 [[raw/知识归档/知识档案/认证材料打磨-二三级边界与案例讲法.md|材料打磨会]] 上继续展开）。
- **三级内容怎么摆？** → A：三级部分里的要素**作为加分项**呈现——"每个人可能没有全部达到三级，但有些项目已经有，那像这都是加分项目"。
