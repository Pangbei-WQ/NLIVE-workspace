# 《供应链的三道防线》读书会第2周学习笔记｜需求预测·数据篇

> **状态**：unreviewed（待人工审核）
> **来源**：[[raw/收件箱/export_1788273921028.md]]（读书会语音转写原稿）
> **周次判定**：转写中分享者自述"从上周（框架）往细讲数据、约四五十页"，对应书中**需求预测「数据」环节**（约 P21–P64 区间），判定为第 2 周。若与实际周次不符请指正。

## 核心要点

- 本周主线：**"从数据开始，由判断结束"——先把"数据"这一半讲透**。存量（旧品）靠历史数据，增量（新品/活动）靠判断加变量，方法论不变。
- **数据有三类**：事务数据（系统导出、最易得）、计划数据（处理后的沉淀）、外来数据（行业趋势 / 竞对 / 市场情报）。**外来数据是当前最大盲区**——没人管、没 KPI、不同步供应链。
- 真实教训：竞对"暑假针"靠低价蚕食份额，前端早看到苗头但从未同步，供应链按挑战目标继续备货 → **信息断链直接造成高库存**。
- **数据口径不统一 = 跨部门吵架的温床**：同是"销量"，财务/订单/不含退货口径不同；送货天数有人报全程有人只认海运段。
- **时间颗粒度之争**：日/周/月预测结果可差 30–40%；倾向性结论是"稳定品与平时按周、大促/学生季按日"，但本质争议被归结为 **IT 处理能力限制**。
- 模型谱系：移动平均 → 指数平滑（刘宝红力荐"滚动平滑"）→ Holt（+趋势）→ Holt-Winters（+季节）；**"参数看不懂就别用，没有信任的模型不如不用"**。
- 组织演进看博弈：PR/PO 合一 → 分离 → 计划职能细分 → 部门墙变厚；华为解法（订单履行部+计划委员会）仍"治标不治本"。
- **多重预测的传话游戏**：销售乐观高估 → 计划经验性打折 → 采购加码 → 供应商冗余，逐层放大（牛鞭效应），谁也不信谁。
- 库存博弈无解死循环：没有"挂靠/担责"机制，跌价算不清 → 前端永远乐观放大 → 供应链弱势兜底。

## 详细内容

### 1. 本周主题：把"数据"讲透

分享者自述：本章节从上周围绕三道防线框架，**往细讲了"数据"这一块，约四五十页、四个要点**。方法论不变，核心仍是：

- **存量** = 以前的历史数据（旧品）
- **增量** = 在数据之上做变量（新品、活动、市场变化）
- 需求预测 = 存量 + 增量，两个都要算进去，缺一不可。

### 2. 数据的三类来源

| 类型 | 来源 | 现状 |
|------|------|------|
| **事务数据** | 管家/系统导出（订单、发货） | 最易得，基本可用 |
| **计划数据** | 事务数据清洗、加工后沉淀 | 现在靠 Excel 手工处理，未成体系、无系统沉淀 |
| **外来数据** | 行业趋势、竞对动向、市场情报 | **最大缺口**：没人管、没 KPI、拿不到 |

对外来数据的讨论最充分（见下节），内部基本共识：一般公司对外来数据**没有明确管理归属**，偏向市场调研职能，且"外部数据要钱的、要整理的，都是有成本的"。

### 3. 外来数据：看得见，够不着

**核心矛盾**：前端（品牌市场 / PPG 侧）其实看得到竞对数据——

- 生意参谋等工具能看到竞对新品、日销、榜单变化；
- 竞对"暑假针"从 20 条链接、单条不高，一路追到"前十有六条是它的、总量反超"，**前端全程看在眼里**；
- 但他们内部开完会就完，**不会协同到供应链**："这跟你供应链没关系啊"，直到销售下滑才回头叫停备货。

**为什么供应链最痛**：
- 供应链若知道竞对低价进攻，当时就该**调低备货预测**，而不是继续朝着"挑战目标"吭哧吭哧备货；
- 前端视角是"市场足够大，我们吃 10% 就行"，没算到市场可能被分流、自家份额被竞对吃掉；
- 结果是七、八月备的货成了高库存。

**解法讨论（方向性）**：
- 前端把竞对/市场分析**拿到周协同会上同步**，供应链才能做应对预案；
- 可以用 **AI 出市场情报周报/日报**（"现在 AI 可以做这个事"）；
- 但要清醒：外部数据对需求预测更多是**佐证**，不是直接输入——比如 7/20 发现挑战目标大概率完不成时，外部数据能加强"该刹车"的判断。

> 📌 转写金句（保留原意）："有数据但没判断、有判断但没数据——最贴数据的是计划；大促该让最了解变量的产品/运营经理做判断，由我们输出足够完善的数据让他们专心判断。"

### 4. 数据口径：跨部门吵架的真正理由

两个被点名的典型：

- **销量口径**：财务销量 / 销售销量 / 订单销量 / 不含退货销量……供应链取"实际发货、刨掉退换货"的财务销量；运营/BI 取数偏乐观虚高。**口径不同，一环环放大，最后变成吵架理由**。
- **送货天数口径**：供应链报 50–60 天（国内发货段 + 海运 + 尾程派送），前端只认"海上 40 天"，每次都要解释一遍。

结论：**跨职能要用同一个口径取数**——本质是"数据清洗 → 内化为计划数据的统一口径"，让后面工作流更顺。

### 5. 时间颗粒度：按日？按周？按月？

**实测差异**：同一需求，按日 vs 按月建模，同一周补货量可差 3000–4000 件（约 30–40%）。

讨论交锋：
- **按日**：杂音大、波动系数高（前日 2000、昨日 4000、明日 3000），且数据量跑不动；
- **按周**：制造业常态，多数稳定品按周补货；指数平滑对"突然增量"的识别会变钝；
- **按月**：太粗，学生季看 90 列数据看不过来；
- 倾向结论：**"一碗水端平"——不同场景不同颗粒度；平时/稳定品按周，大促/学生季按日**（日数据需 IT 支撑）。

> 🔍 **综合判断**：颗粒度分歧的底层其实是 **IT 数据能力**——按天处理不过来才退回按周；若系统能承载日级，预测精度上限更高。此为结合讨论内容的推断。

### 6. 预测模型谱系（书 + 现场讨论）

- 由简到繁：**移动平均**（稳定品）→ **指数平滑**（刘宝红强烈推荐，称"平滑滚动法"，能识别突发增量）→ **Holt 模型**（有趋势）→ **Holt-Winters**（趋势 + 季节性）；
- 更复杂/先进的版本现场有人查过（音近"霍格/霍尔特温特"），找不到可靠下载；
- **关键态度**：模型系数设定自己都看不明白，就别直接上——过程、结果都得不到自己信任，不如沿用现有做法；
- 有趋势 + 季节性明显的品，**群策群力/专家判断**比硬套模型更稳，还能把博弈摆到台面上。

### 7. 组织演进与博弈（书的案例映射到自己公司）

**PR/PO 职能演进四阶段**（分享者指其普遍性，非某公司特例）：

1. **起步期**：采购全包，既做 PR 也做 PO（≈ 现在 PMC 经理一人承担日常职能）；
2. **站稳期**：PR/PO 分离，降内控风险、各自专注；
3. **Top 级阵地战**：计划职能细分（市场计划 / SOP / 主计划 / 生产计划 / 物料计划），甚至自建车间；
4. **体量再大**：规范了，但客户觉得交付变长、管理层觉得库存变多，**部门墙和协同瓶颈越来越大**。

**华为解法**（作为行业对照）：
- **订单履行部**：客户"驻点代表"，统筹订单交付承诺与达成，是"铁三角（产品-计划-订单）"关键组成；
- **计划委员会**：专解决策——提前备货、产品切换、最后一次采购、短缺风控协调；
- 但书中观点：**这仍是治标不治本**，更好的方法要靠自己探索。

### 8. 多重预测的"传话游戏"（外部博弈）

预测链条层层加码，谁都不信谁：

```
销售预测（业绩导向，乐观高估）
  → 计划经验性打折
    → 采购预测加码
      → 供应商留冗余
```

每层都在放大需求 → 牛鞭效应。内部同理：运营给产品掺水、产品给供应链掺水，**谁对库存不担责，博弈就永远偏向放大**。仓库真实照片是"货都堆到一楼、脸盆搓衣板成山"。

### 9. 库存博弈：为什么是个死循环

- 现状：供应链像"大池子"，交付时谁库存大谁占便宜、能分到货；**一旦库存多出来，只能按财务分摊——谁卖得多谁多摊**；
- 库存跌价算不清楚 → 大家无所谓 → 前端继续乐观 → **死循环**；
- 现场介绍的外部做法（可借鉴）：
  1. **摊利润法**：通知时限内，滞销货成本价直接从运营利润里扣（提成已含成本）；
  2. **归零 + 分摊法**：既往滞销成本公司归零，之后新增按比例与运营/产品分摊——不打击销售信心；
  3. **责任判定法**：判定滞销是谁产生的，供应链自身产生的就对折扣绩效。
- 现实阻力：公司产品多渠道销售、不挂靠到个人，"记在谁头上都会闹"，**集体执行难**；分享者坦言"待过的所有公司都没有这种挂靠机制"。

### 10. 学生季复盘：目标、供应商、成本三层账

**目标倒逼链条（前端）**：
- PPG 定 1.5 亿 → CPG 说做不到 → 调到 1.5 亿再拆，各渠道只敢领 2000–3000 万 → 被倒逼加码到 5000 万 → 仍无渠道真正领走业绩目标；
- 达人只做计划的一两成（1000 条视频只拍 100 多条）、达人经理 3 人只剩 1 人 → 前端执行与目标严重脱节；
- **供应链要不到"保底"**——多方默认"保底 = 去年的量"。供应链方主张：超保底的部分全部重新走决策，否则不备。

**供应商连锁反应（海得利案例）**：
- 原给预测做到 8/20，工人照此安排；8 月突然断单 → 工人何去何从、再招人难；
- 供需信任破裂：明年你再催货，"我就慢慢来"；明年谈价被动（说好 30 万量只做了 12–13 万）；现金流被高库存压住。

**成本结构反思（水桶案例）**：
- 售价约 25 元：货品成本 ~7 元（占 20%+）+ 推广 ~30%（10 元+）+ 快递/仓储/模具分摊/管理费；
- 销售价倍率约 4.12 倍（品牌预期 5 倍），竞对低价仍有利润 → 问题不在进货价，在**推广费占比过高、销售价无竞争力**（同款竞对卖 10 元我们卖 25 元）；
- 讨论质疑：产品无壁垒（家居百货谁便宜谁上），利润薄到"卖 5 万赚几百块"仍是常态。

### 11. 本轮指向的待办（读书会内部提出）

- 大促/大战役预测，让**最了解变量的产品/运营经理介入判断**，供应链输出完善数据支撑其判断；
- 要求前端把**外来数据（竞对/市场情报）纳入周协同会同步**，可用 AI 生成周报；
- 推动**数据口径统一**与需求预测的 IT 化沉淀（否则"闭环复盘"永远做不到）；
- 供应链守住**保底 = 去年量**的底线，超保底即要求重新决策评审；
- 下次复盘（约 9 月）对照书中方法，逐个环节找问题点，**留好会议纪要/需求评审记录，不做背锅侠**。
