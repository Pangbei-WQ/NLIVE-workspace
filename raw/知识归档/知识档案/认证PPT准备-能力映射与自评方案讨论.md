# 认证 PPT 准备｜能力映射与自评方案讨论

> **状态**：unreviewed（待人工审核）
> **来源**：[[raw/收件箱/export_1788273816926.md]]（会议语音转写原稿，约 21 分钟）
> **会议性质**：认证 PPT 的**结构评审 + 映射方案定调**。被辅导者先讲自己设计的主线，辅导者逐段给建议，重点解决"26 项要素怎么在 PPT 上体现、评委怎么打分"这个核心难题。
> ⚠️ 转写为人名/术语识别结果，可能不准。

## 核心要点

- **PPT 不在多，核心是内容讲得通透、逻辑闭环。** "职责理解是否 OK，然后怎么做映射的动作"。
- **映射方案定案（辅导者推荐的"最佳实践"）**：把 **26 项要素全部列在 PPT 边缘**，讲到哪页就**高亮本页覆盖的那几项**，同时给一条**累计进度条**——"本页覆盖 3 项 / 累计 15 项 / 总进度 XX%"。一页解决两个问题：本页具备什么能力 + 目前总的积累进度。
- 另一种做法：每个核心篇幅**后面紧跟一页映射**（当下巩固），或最后统一做一页**总汇总**（最后巩固）——两者都行，但**间隔久了印象会弱**。
- **证据材料必须排序**：先做**证据清单**（101、102、103……每条对应说明什么、放在哪里），底稿 → 再生成 PPT。
- **每个讲点要提炼"解读含义"**：把该要素背后的关键字标在节点上，否则"讲着讲着就丢了"，评委**打不了分**。
- **最后加一页"综合自评"**：我自己认知的现状 + 每页制一份自评，供评委参考（评委对规则不熟、来不及打分时可直接对照）。
- **知识技能的考核方式要重定**——公司当天提出新要求：是笔试，还是选择题/判断题/描述题/答辩题？**次日给方案**。
- 先出 **5 个案例 → 26 要素覆盖情况表**，PPT 后做；而且第一版只需讲一个 **MVP**，明确告诉评委"我不是已经全部准备好材料，而是先讲一个 MVP 给你看"。
- 辅导者的判断：**"你们已经跑得比他们快很多了""要有信心，放心一定过，不要带着包袱去讲。"**

## 详细内容

### 1. 被辅导者原先设计的 PPT 主线

| 顺序 | 内容 |
|:--:|------|
| 1 | 直接告诉评委：我要认证几级、来自哪个部门 |
| 2 | 自我介绍：入职时间、负责过的业务线、目前的核心能力 |
| 3 | 为什么我要认证二级 |
| 4 | 我对岗位职责的认知（**五个要素**） |
| 5 | 库存计划表的逻辑、管控规则、数据来源 |
| 6 | 结合 to B 订单需求影响，分析我怎么判断与排期 |
| 7 | 重点讲**难点在哪** → "分析框架·五步决策链" |
| 8 | 五步决策的详细数据讲解 |
| 9 | 通过案例说明要跨部门协调哪些岗位 |

> 📌 辅导者对第 4 点的提醒："这里会有一个挑战点——你怎么区分这十条在**一到六级**里面的映射关系？但对你来说不用讲一条路径，**讲二到三级的边界在哪里**就可以了。"
> 第 9 点的补强建议：把**质量、货代、物联网、公开**等协同方都塞进案例里一起讲掉，"不用单独再讲"，"这样这个岗位的挑战难度就会更高"。

### 2. 辅导者的核心逻辑：职责等级是"最底层的能力"

> 📌 "为什么我们一直强调**职责等级**？这其实是一个等级，是最底层的能力。我对我职责了解得很深，我知道这些职责映射到一到三级，它到底等级怎么界限、怎么区分，那我就明白说我平时该干什么、干到什么程度。"

- 未来不是"为了认证而认证"，而是**在日常工作中有意识地培养自己三级的能力**；
- 这一轮只是先让大家**有体感**；真正的积累发生在日常工作、绩效场景、项目里；
- 落地方式：把"我要培养这两项能力"直接写进 **PPC（个人绩效）**，"原来我每个月都要关注这个东西，这才是我未来发展的方向"。

**被辅导者漏掉的关键词：主导。**
> 📌 "哪些是你**主导**的，哪些是你**独立能做**的。"——讲的时候顺手融入进去，"既然都讲了，干嘛不融入进去？补几个字眼就搞定了。"

### 3. 两种映射讲法，以及辅导者推荐的呈现方式

**问题**：如果在业务案例里顺带讲，映射会**混乱**——"不管你提的建议是对的、二的还是对的，直接展开，评委听不全"。

**方案 A：讲业务主体，自然覆盖**
- 风险：评委只能听到一两个关键词，"那够不够？不太够"。

**方案 B（辅导者推荐）：要素清单常驻 + 本页高亮 + 累计进度**

> 📌 "26 个全部干在边上，然后这页高亮……然后总的：这是这一页高亮里的，然后总的目前覆盖多少。"

具体形态：
- **侧面/底部常驻 26 项清单**；
- 讲到某页 → **高亮本页覆盖的项**；
- 同一页再给一个**累计进度**：本页覆盖 N 项 / 累计已覆盖 XX 项 / 总进度百分比；
- 效果：一页同时回答"这页我具备什么能力"和"我总的积累进度到哪了"。

**方案 C：前后加汇总**
- **当下巩固**：每个核心篇幅后紧跟一页映射；
- **最后巩固**：全篇结束做一页总整合（"我第一页整理下来……总的来说覆盖了这些"）。
- 辅导者评价：两种都行，但**最后做间隔太久，印象会弱**，"最好是很顺"。

**方案 D（参会者提出）**：把 26 项全部列出来让评委知道是什么，本页勾选，另加两行——第一行"本页体现"，第二行"累计已满足 N 个"。

**另一条实操建议**：用类似"索引/标注"的方式，在文本里**直接标小序号（上标）**——"我未来要讲这段，哪条怎么标"，讲的时候给自己一个提示，也不占空间。

### 4. 讲法上的三个技术要点

1. **每个节点的"解读含义"要提炼出来**
   > 📌 "他背后有一句话关键字可能要提炼到这里……就是这个字眼的含义是什么。**怕记不住，你讲的时候可能讲着讲着就丢了。**"
   - 例："信息收集"的关键词是"**多渠道**"；二级的关键词是"**独立** + 复杂场景/多产品/沉淀"。
2. **边界与接口（KOS/KS）必须能解释**
   > 📌 "你一定要很清楚知道**中间件是什么**，因为它原始有解释。不然你讲着讲着，可能按照你的思路讲完之后看上去覆盖了，**但评委打不了分**。"
3. **证据材料必须排序**
   > 📌 "**所有证据都要进行排序**，你是先要有**证据清单**的……你现在举证，比方说有 3 个或 5 个材料，101 到 105，01 对应什么、02 对应什么、03 对应什么，**带着文字说明要放到哪里**——那份是你的底稿，底稿再生成你的 PPT。"

   （原话还提到"底稿不要用手机就行了"，转写噪声，疑为"底稿不要放进 PPT 里"。）

### 5. 自评设计

- **价值**：评委对这套规则**并不熟悉**——
  > 📌 "评委现在肯定也是懵逼的状态。除了你对规则非常熟悉，其他人根本就不熟悉……讲是讲过，但不一定能听得懂。"
- **做法**：在**每一页**做一份自评，评委可直接参考，"评委停下来来不及打分"时就能对照。
- **辅导者给这种做法的内部叫法**（转写噪声，音近"暗时期"）——意思是**不做声张的引导**。
- **自评的定义（辅导者口径）**："我认知自己目前的现状，是否足够有引导性。"呈现方式待定，"有可能他们选表格，那我请他们审，我现在不太确定"。
- **自评放在哪**：不在"工作职责"那一页（那页没有评分项），**只加在三要素（知识技能、行为标准、数据能力）那里**；映射到 26 条时给自己打分，是**逐条打分**，不是最后统一打分。

### 6. 版本与时间安排

| 事项 | 结论 |
|------|------|
| 下一步先做什么 | **先整理 5 个案例 → 映射到 26 要素的覆盖情况表**，先不做成 PPT |
| 为什么 | "你们讲的是 **MVP** 嘛——讲一个 MVP 怎么覆盖、逻辑是不是能讲得通、底层是不是对" |
| 开场口径 | 一开始就告诉评委"**我不是已经全部准备好所有材料，而是先讲一个 MVP 给你看**"，虚心听需求方意见（提到罗婷婷） |
| 页数 | 会上提到"16 页"→ 辅导者建议 **10 页**；但"你案例还会再增加，PPT 应该超过十页，十几页的样子" |
| 时长 | 明天拉日程，**60 分钟**；今天只讲了 16 分钟，因为只负责一个案例，"要再加案例才能全部覆盖" |
| 倒数第二页 | **不要写"协议"、不要写"电话管理"**；"领导的上级"→ 写"对上级"；"同事/专家支持""学习用支持"**不要写** |
| 呈现工具 | **PPT 优于表格**——"因为这样他会很顺"；表格需要自己有很强的底层逻辑才能讲清楚 |
| 知识技能考核 | 公司当天提出新要求：**单独讨论怎么考核更好**（笔试？选择题/判断题/描述题/答辩题？）→ **明天给方案** |

### 7. 其他提醒

- **想预认证的都可以报名**："又没说要限制，预认证又没压力，就是拿出来让所有帮我帮你把关一下。"
- 辅导者提到向华科的 HRBP 取经："他也是用**华为体系一模一样**，但他的做法是整个变异掉。"
- 一段关于干部培训的自我提醒："我这周还要准备看一下干部怎么培训他们？机制怎么培训？我还没想好怎么弄。或者先按整个进度看你们进度，如果进度来得及就再培训，来不及就放到周一。"
