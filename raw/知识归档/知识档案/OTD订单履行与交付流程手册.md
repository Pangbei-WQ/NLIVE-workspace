## 核心要点

- **一句话定位**：这是公司**交付链路的母流程**，把「接单 → 备货 → 采购 → 生产 → 入库 → 发货 → 交付 → 复盘」端到端拉通，**PMC 经理是这条链路里的执行承接环节**。
- **目的**：承接前端需求、拉通后端供应，实现"以客户为中心"的高效交付，同时**平衡交付效率、成本与客户满意度**。
- **适用范围**：百货、跨境、品牌线等**全部业务线**；覆盖货架渠道、内容渠道、分销等**全部渠道**。
- **流程活动共 20 个**（001–020）+ 3 个外接流程（ITR / IPD / 门店运营），每个活动都定义了**负责职位 / 详细步骤 / 输入 / 输出**。
- **角色共 10 类**：SCC 供应链委员会、交付经理、运营经理、供开经理、**PMC 经理**、客户成功经理、质量经理、库流经理、FBP 经理、效率 BP。
- **绩效指标 7 个**：周转率、滞销率、订单有货率、售后质量率、综合成本利润率、揽收及时率、售罄率（可选）。
- **决策机制**：SCC 采用**民主集中投票制，SCC 主任有一票否决权**。
- ⚠️ **对 PMC 的关键含义**：手册把 PMC 明确定位为**承接交付经理的采购计划去执行**（转采购单 → 跟交期 → 协同到货 → 统计供方表现），**计划源头在交付经理**。这正是认证「对上级/上游的依赖度」讨论中的事实依据。

## 详细内容

### 一、目的与适用范围

**1 目的**：基于公司战略规划，通过系统化、标准化的流程管理，承接前端需求，拉通后端供应，实现高效的前后端协同，实现"以客户为中心"的高效交付；同时平衡交付效率、成本与客户满意度，实现交付成功，最终支撑企业的市场竞争力与可持续发展。

**2 适用范围**：适用于公司的**百货、跨境、品牌线**等所有业务线的订单交付，覆盖所有线上货架渠道、内容渠道、分销等所有渠道。

### 三、术语和定义（4.）

| 缩写 | 全称 | 定义 |
|:----:|------|------|
| **FR** | Fulfillment Responsible | **交付经理**。在项目/服务/产品从规划到交付客户的全流程中，负责统筹协调、风险管控、资源整合，确保交付目标（质量、时效、成本、客户满意度）达成的核心管理角色 |
| **OTD** | Order to Delivery | **订单履行交付流程**。从接收客户订单开始，经订单处理、生产/采购、物流运输、库存管理、包装、快递配送，最终将符合客户要求的产品/服务交付至客户手中，并完成收尾确认的端到端全流程 |
| **MM** | Marketing Management | 市场规划到执行流程：从市场需求洞察出发，目标设定、策略制定、营销活动落地执行、效果监控与优化的全链路管理 |
| **IPD** | Integrated Product Development | 集成产品开发流程：跨职能团队协作 + 并行工程，以市场和客户需求为驱动，从概念到退市全生命周期高效管理的系统化方法论 |
| **SCC** | Supply Chain Council | **供应链委员会**。推动供应链管理委员会决策机制的组织，致力于提高供应链效率、提升竞争力 |
| **ITR** | Issue to Resolution | 问题解决流程：从客服问题被识别、记录，到分析、处理、解决，直至复盘总结的全生命周期管理 |
| — | 供应商库 | 纳入公司管理范围的合格供应商库 |

### 四、角色及职责（5.）—— 10 类角色

**SCC（供应链委员会）**

1. 组建 OTD 一条龙团队，审批并指定 OTD 一条龙经理
2. 接受 OTD 订单履行策略评审需求，结合公司战略目标和订单履行现状，分析开发供应商的必要性
3. 召开评审会议，依据评审标准对 OTD 的预测计划进行初步评审，确保目标和策略与公司战略一致
4. 评估订单履行策略和工作计划实施的可行性和风险，给出调整建议和资源协调支持
5. 最终批准调整优化后的供应商开发策略和工作计划
6. 根据市场变化和公司战略调整，定期回顾并调整供应商开发策略和工作计划
7. 对供应链的关键事项进行风险评估及决策评审

**交付经理（FR）** —— 本流程的**中枢角色**

1. 主导协同 OTD 订单履行交付的**流程端到端闭环管理**，整合跨部门在产品需求计划上的最佳预测与判定，实现供方及内部的最优资源协同
2. 主导协同推进各部门对 OTD 相关协同工作的落地与实施，包括需求预测、风险识别、库存监控、采购实施、需求纠偏、突发供应风险应对、缺货识别及应对、交付时效风险识别及应对
3. 基于客观的需求预测，**转化为实际可行的库存计划**，实施推进库存计划落地，并进行计划的日常闭环监控与纠偏
4. **构建基于历史销售数据的需求预测模型**，契合平台、产品、供方特性
5. 主导 OTD 相关的协同会，如评审会等
6. 参与并转化接收 MM/IPD/1→N/供应商库/运营流程/ITR/IPMS/战役等流程的 OTD 相关协同与规划

**运营经理**

1. 商品信息合规化：确保标题、规格、库存数量准确（"预售""现货"标签清晰），避免订单取消或投诉
2. 价格与活动设计：通过定价、优惠券、满减控制订单节奏（避免短期爆单导致仓库爆仓），确保活动规则清晰（如发货时间）
3. 协同交付经理监控与优化履约效率指标：发货时效、配送时效
4. 针对策略性需求与交付经理协同：同步交付需求变化，推动协同补货
5. 与客服团队协同：共享订单与物流信息
6. 与平台运营协同：跟进平台交付发货规则调整，避免违规处罚

**供开经理**

1. 需要时参与需求计划评审，基于供应商资源库和历史数据，评估关键物料/产品的供应可行性
2. 提供**供应商产能基线、交付周期、最小起订量**等核心数据，协商弹性产能储备（季节高峰产能预留）
3. 针对非常规订单（大额、紧急），快速联动核心供应商确认临时产能，为订单是否可接提供决策依据
4. 主导供应商开发与优化，优化供应商结构，消除供应风险
5. 协同供应商产能与交付管理：签订交付协议（交付周期、质量标准、违约责任），定期评估产能利用率、历史交付准时率
6. 协同处理供应异常：延时交付、质量不达标时，协调加急生产、切换备选供应商或与客户协商调整交付时间

**PMC 经理** ⭐ （本流程中 PMC 的定位）

1. **根据交付经理的计划**，转化采购单，确认物料规格、数量、单价、交期等信息
2. 与供应商沟通订单细节，获取订单确认回执，确保双方信息一致；跟踪采购订单的生产、发货进度，定期与供应商确认交期，**提前预警延迟风险**
3. 协调仓库做好收货准备，处理短交、错发、质量不合格等问题（退换货、补货）；向仓库等部门同步订单进度及异常信息
4. 收集供应商的产能、交货能力等信息，辅助供应商交付能力评估
5. 统计采购订单的**准时交付率、合格率**等数据，协助分析供应商表现

**客户成功经理**

1. 针对交付过程中的客户需求及时反馈，协同各部门快速闭环处理，保障交付满意度
2. 涉及缺货及交付异常时与客户沟通协商，避免满意度进一步下降
3. 从客服角度监控订单交付的店铺评分及满意度，反馈交付经理协同优化
4. 监控 DSR 评分、响应时效、投诉率等指标
5. 实施到货关怀与使用指导

**质量经理**

1. 闭环应对供方端、仓库端、发货端等交付链路中的质量风险
2. 针对不同事业部需要，组织安排供方发货端的质量监控（获取供方报告、现场验收、委托第三方验收），确保到仓入库品合格
3. 组织入库的抽检抽查，避免不良流入后端及客户环节
4. 代发产品定期抽检
5. 库存次品监控，协同仓库及相关部门及时处理

**库流经理**

1. 依据需求计划进行人员安排及耗材筹备
2. 例行开展盘点工作，确保库存准确性
3. 统筹规划仓库接单及配货策略，确保发货及时性
4. 规范化、标准化配货发货各环节，避免错漏发
5. 协同质量经理，安排对供方到货进行抽检，及时拦截到货风险
6. 监督仓库快递服务商的揽收服务质量及时效
7. 品牌线组装产品质量的过程把控

**FBP 经理**

1. **付款审核**：采购付款单、退换单、异常单审核；仓库账单数据、代发快递费审核；仓库物流账单审核
2. **本部总账**：各仓库库存出入库数据核算；供应商明细账、材料账应收对账表；在途产品报表编制、确认及跟踪；店铺收入、成本、前中台费用凭证处理；销售收款数据核对

**效率 BP**

1. 流程监控与预警：协同交付团队建立**实时可视化看板**，跟踪订单接收→生产→发货→交付全流程，设置关键节点异常预警
2. 需求预测与规划协同：协同交付经理，开发预测模型预估订单量峰值和交付资源需求
3. 库存监控：建立实时可视化看板，监控库存支持产能和库存规划，监控产品状态是否滞销

#### 专栏 A：预测协同策略（活动 003 · 原文照录）

1. 针对**稳定的老品**，因历史数据对预测的影响权重更大，**交付经理预测为准**，运营经理及市场经理判断为辅。
2. 针对**新品**，因参考历史数据进行预测的权重较低，**交付经理的最终预测需要更多结合运营经理及市场经理的判断**。
3. 涉及**市场策略及战役波动**影响，交付经理进行最终预测时，须与相关协同方进行**联合判断**。

#### 专栏 B：分品类备货策略与推拉结合点（活动 006 · 原文照录）

1. PMC 经理须提前获悉了解供方的生产协同诉求，结合内部的交货计划进行双方最优方式的协同配合。
2. **大体积占空间的注塑类**：正常生产周期 < 7 天，供方可快速响应，但体积大会影响供方仓储空间使用率 → 可**按单生产按单交货**。
3. **小体积不占空间的注塑类**：可选择**供方现场成品备料**。
4. **毛绒布艺类**：正常交期 45 天，采购成本较高；布料备料周期长、手工作业工序多、供方提前排产刚性、成品不占空间可堆叠 → 供方愿意配合时可**原料备料 + 成品备料的多个推拉结合点**的现场备货。
5. **电子类**：正常交期 < 30 天，周期瓶颈在电子原材料、组装工序多、供方有提前排产刚性、成品体积较大 → 可**原料备料 + 成品订单**。
6. **彩盒等带空间的包材类**：正常交期 < 20 天，供方有提前排产刚性、材料备料需周期、成品体积较大 → 可**原材料备料 + 成品订单**。
7. **木艺类**：正常交期 < 60 天，供方有提前排产刚性、材料备料需周期、排产工序多、关联成本较高 → 正常**按单下单生产**。
8. **低货值高消耗不易盘点的耗材**：货值低、准确盘点效益不高 → 可采用**按起订量双堆（双桶）备货**。

#### 专栏 C：库存计划（活动 007 · 原文照录）

1. **再订货点库存结构** = 生产周期库存 + 物流周期库存（陆运 + 海运等）+ 周末周期库存 + 安全库存（销售波动 + 供方交货风险波动 + 需保障的服务水平）。
2. 协同采购设定到货周期（含物流周期），设定安全库存（基于销量波动性 + 及时交货率需求，**24 小时 > 95%，48 小时 > 99%**）。
3. 安全库存来自：销量波动、供应风险、服务保障水平。
4. 供应风险不易结构化统计，可**经验性提供交期的波动性差值**增加库存天数。
5. 销量波动性测算须**剥离活动等异常因子**，测算波动系数标准差。
6. 服务水平区分不同款定义，**正常水平 > 99.8%**。
7. **库存结构拆分** = 安全库存 + 周转库存 + 过剩库存 + 风险库存（超 90 天）+ 滞销库存（无动销）。
8. **SKU 库存有货状态分级**：0 库存 / 缺货 < 5 天 / 5 天 < 低库存预警 < 15 天 / 15 天 < 正常库存 < 30 天 / 30 天 < 过高库存 < 60 天 / 60 天 < 超高库存 < 90 天 / 90 天 < 滞销库存 / 无动销。
9. **分品类库存策略**：百货＝不定时 + 不定量结合及其他组合策略；品牌线＝不定时 + 定量与不定量结合；跨境＝**定时 + 不定量**结合。
10. 依据销量及规模动态调整库存计划策略，兼顾运营成品及交货率下的库存最优。
11. **SKU 分类管理（A/B/C 类）**：
    - **A 类**：日销采购额累积降序前 **80%**，缺货属紧急重要事项须第一时间闭环。**百货销量缺货率控制 < 99.9%，跨境东南亚有货率控制 < 98%，品牌线销量有货率 < 99.99%**。
    - **B 类**：累积额 **80%～95%**，缺货同样紧急重要。**销量缺货率控制 < 99.8%，跨境东南亚有货率控制 < 97%，品牌线销量有货率 < 99.9%**。
    - **C 类**：累积额 **95%～100%**，订货须结合滞销风险考量，可联合判断是否评估清库。
    - 不在相应比率范围内但基于其他维度重要性的，可单独标记纳入相应类别管理。
    - **组合装分类须考量相应 SKU 对关联组合的影响**（如品牌线低货值组件可能关联高价值礼盒）。
    - 分类可依实际状况动态调整。
12. 交付经理须依公司战略规划及前端需求计划，及时协同库流经理对**仓库的选择、布局提前规划**（主仓、云仓、海外仓）；库流经理进行仓库日程管控与优化。
13. OTD 涉及 IPD、1-N、质量改善等流程触发并接受到的产品变更（结构、外观、包装、标签、礼盒组合方式），交付经理须及时协同 PMC 经理、库存经理、质量经理执行（库存消耗、库存终止、协同供方库存盘点、前后变更切换、主仓库存盘点等）。

#### 专栏 D：缺货管控与应对（活动 016 · 原文照录）

1. 设置不同品的**缺货管控水平**；进行缺货例行监控。
2. 建立缺货日常监控数据：**SKU 缺货率、销量缺货率、订单缺货率、赔付情况**等。
3. 构建缺货闭环跟踪机制，目前**百货 & 品牌线主要以仓库的缺货清单进行即时监控**。
4. 订单管理组成员形成**周缺货汇报复盘机制**，跟踪闭环并做组内最佳实践经验横向同频。
5. 缺货应对及周期性复盘，迭代备货逻辑策略。
6. 缺货预警发生时，交付经理主导协同各部门应对：
   1) **区分缺货原因**驱动应对：缩短供方交期、临行加急方案、替发方案、次品快速返工方案、紧急启动二供评估、客户沟通方案；
   2) 库存有限时组织协同部门沟通，必要时**进行不同渠道的库存分配**，确保全局分配最优，**原则上首选保障货架渠道重要链接**；
   3) 复盘缺货原因做后续预防（安全库存设置、供方交期跟踪、质量风险改善）。
   4) 细节参考《**缺货管理办法**》。

### 六、流程绩效指标（7.）

| 指标名称 | 指标定义 | 计算公式 |
|---------|---------|---------|
| **周转率** | 衡量库存资金流转速度的核心效率指标，反映资源配置效能与资产健康度 | 周转率 = 30 天销售成本 ÷ 30 天平均库存余额 |
| **滞销率** | 识别商品积压风险的敏感性指标，通过监控长期无销售库存释放无效资金占用，指导品类结构优化 | 滞销率 = 超 90 天滞销品滞销金额数 ÷ 总库存金额 |
| **订单有货率** | 供应链响应能力的核心评价指标，直接体现客户需求满足的服务水平 | 订单有货率 = 可立即发货订单数 ÷ 总订单数 |
| **售后质量率**（错漏发、质量问题） | 综合评估错发/漏发及商品缺陷的服务质量指标，驱动逆向流程优化与质量改进 | 售后质量率 = 1 − 错漏发、质量问题订单数 ÷ 总订单数 |
| **综合成本利润率** | 交付过程中综合性评估指标，揭示供应链全链路成本控制水平 | 综合成本利润率 = 供应链全链成品 ÷ 销售额 |
| **揽收及时率** | 近 30 天揽收时间（支付到揽收的时长）早于或等于 48 小时（设置发货时效的按设置时间）的订单占比 | 48 小时揽收及时率 = 近 30 天揽收超时订单笔数 ÷ 近 30 天应揽收订单笔数 |
| **售罄率**（可选指标，依交付客户对象而定） | 一段目标期间内，售罄率高说明产品畅销符合市场需求；反之可能意味着设计、价格或营销问题，或备货不合理 | 售罄率 = 期间销售数量 ÷ 期初库存数量 × 100% |

> 📌 注：原文「揽收及时率」的定义（早于/等于 48 小时占比）与公式（超时笔数 ÷ 应揽收笔数）**口径方向相反**，疑为原文笔误，已在「待补充」标注，未擅自改动。
