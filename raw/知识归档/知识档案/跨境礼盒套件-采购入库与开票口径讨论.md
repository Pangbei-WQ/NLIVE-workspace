# 跨境礼盒套件｜采购入库与开票口径讨论

## 核心要点

- **场景**：一批 7 月发出的货**已到仓**，本月就要开始卖 → **必须先把采购入库做掉**，但采购单与实发对不上。
- **数据不完善的根因**：采购单写"下单 200 套 / 每种 200 个"，**实际发货没有那么多**，差额后面从主仓补 → 采购单、实发、入库三边对不上。
- **供应商主体建模问题**：实际结算是**从英式拿货**，但系统里没建"英式"，会被误读成"从百货拿货"。**建议单独建英式的供应商/仓库**，因为**与百货的结算价格不一样**。
- **价格口径**：现有供应商价格**已含 10% 含税价**；主仓原来按 **8 个点**。
- **开票原则：谁采谁开**——
  - 整套都从同一家采 → **可以直接开整套**（需提供明细/SKU）；
  - **有外有内**（部分外采、部分主仓组装）→ 只能按实际**分开开**，或按单品开。
- **SKU 编码**：跨境有**专属编码**；需把"组合套由什么构成"的明细给到供应商。管家里对应的是"**货品编码 / SKU**"。
- **执行建议**：后续量大了，**直接跟对方定三件套**，省得来回拆；若进的就是五件套，则我方要多采两件再自行拆组。

## 详细内容

### 1. 为什么必须马上入库

> 📌 "这批货其实是已经到仓了……他 8 月份查出来的东西做成品应该卖了，现在肯定要入库。"

- 货已发货出去（7 月发出）、已到仓 → **这个月就要开始卖**；
- 入库需要单价与 SKU，但采购单**还没完善** → "你让我用啥数据入"。

### 2. 采购单与实发的差额

| 环节 | 实际情况 |
|------|----------|
| 采购单 | 每种下 **200 个** / 共 **200 套** |
| 实际发货 | **没有发这么多**，部分**从主仓补** |
| 采购单登记 | 后续补的部分**还没做进采购单**（"就还没全部还没到"） |

> 📌 与会者判断："正常来讲你采购订单肯定是要做清楚的……你现在是采购订单你这边还没有，**相当于你这边的数据是不完善的**。"

### 3. 供应商与仓库建模

**问题**：系统里"福州主仓"是默认发货仓，其他供应商则按供应商仓库命名。这批货实际是**从英式拿的**，但：

> 📌 "如果从他们那个角度来讲，你这边就不是写福州主仓，应该写……不然的话他们会**误解为这个是百货那边的拿货**。"

> 📌 "你实际上结算的是……那其实这里面都看不到怎么是从英式里面拿货的那几个部分。"（提到了"优选仓"，但"优选仓里但是这个是百货的"）

**建议**

1. **单独建一个"英式"的供应商/仓库**——
   > 📌 "跟百货之间结算的那个价格不一样嘛。"
2. 采购入库时按**含税成本**入账（现有供应商价格已含 10% 含税价）；
3. 主仓原来的口径按 **8 个点**，与会者确认"你就按你发我那份组件来的，这个其实就是管家上的价格"，即**裸价 → 含税**的换算关系要写清楚；
4. 主仓与英式的成本口径差异要在建单时说清，避免后续结算打架。

### 4. 开票口径（重点）

**总原则：谁采谁开、按实际开。**

> 📌 "他根据实际来嘛，我跟谁采，我就跟谁找谁开。……反正我们税点都付掉了，找供应商张开是必然的。然后从他们这拿货的就找你们算，然后就是加八个点，然后你建单的时候就相当于是建含税。"

**组合套 vs 单品**

- 若**整套都从同一家采** → "你就直接给我开一个这个东西就行了"（可直接开整套）；
- 若**有外有内**（部分外采、部分主仓拿） → "那你就只能分开开"，或按单品开；
- 供应商的**出库方式是单品**，组套后开给跨境——
  > 📌 "你出库是出的这个三件套，不是你出库是单品，然后组成了这个开给我。"（随后修正为：**入库按单品、开票按组合套**更可行）

**难点：组合套的构成必须给到供应商**

> 📌 "你要把这个明细给我……我给你明细，然后你直接给我开八件套。"
> 📌 "你管家查不到，可能我要把这个……那你可能得把他这的 SKU 给到他。"

- 跨境有**专属编码**，需要把组合套（如"花园摇椅八件套"由哪几个单品构成）的 **SKU 明细**提供给供应商；
- 管家里对应的是"**货品编码 / SKU**"（"这一排嘛，这是货品编码嘛"）。

### 5. 五件套 → 三件套的拆组问题

**现状**：某系列（"音乐 110"）英式那边是**按五件套卖**，现在需要**拆成一个二、一个三**。

**两种处理**

| 情形 | 建议 |
|------|------|
| 若供应商入库**就是五件套** | 让**英式那边拆**成单品/三件套再入库 |
| 若拆不了 | 我方**多采那两件**，自行拆组，余量重新入库 |
| 后续量大 | **直接跟对方定三件套**，"省得你再省得他们再拆了" |

> 📌 "理论上来讲，我应该是给他五件套采进来，完了以后我拆出来再去组合，然后剩下的两件套再上到我自己的仓库里面，然后再在后面再组。"
