
### 一.Claude Code 插件升级后 DeepSeek 用不了

现象

[[VS Code]] 上装的 [[Claude Code|Claude 插件]]自动更新后，自己接的 [[DeepSeek]] 模型报错，提示 role 字段不合法——[[API]] 只认 user 和 assistant，不认 system 了。

原因

Claude Code 插件更新改了角色的配置规则，新版本不再支持 system 这个角色。DeepSeek 兼容 Claude API 时还在用旧的 system 消息格式，两边对不上。

处理

把 Claude 插件版本回退到两天前的版本，重启 VS Code，恢复正常使用。

### 三.--slim 是什么

作用

--slim 是订货表生成脚本自带的参数，不是 [[Claude Code]] 内置参数。不加 --slim 时输出完整表格（原数据 + [[安全库存]] + 波动系数 + [[建议订货量]]），加了之后只输出最终结果列，去掉所有中间计算列。简单说就是只给结果、不给过程，输出更短更干净，方便直接复制到系统。

区别

Claude Code 内置的 /compact 用于压缩对话历史省 token，/fast 用于切轻量模型加快速度但质量略降。而 --slim 是业务脚本自定义的参数，只控制输出格式，和 Claude 内核无关。

例子

不加 --slim 输出的是完整表格：物料号、现有库存、安全库存、波动系数、建议订货量全部显示。加 --slim 后只保留物料号和建议订货量两列，甚至极致精简到只剩数字。

用途

只要最终订货数字不要中间过程时、要复制进 [[ERP]] 或下单系统而列太多会报错时、想看得清爽少刷屏时，就用 --slim。

### 四.Clawd-on-Desk 版本选择（Windows）

结论

绝大多数 Windows 用户（[[Intel]]/[[AMD]] 处理器）直接下载 **Clawd-on-Desk-Setup-0.8.1-x64.exe**。这是 64 位标准安装包，适配 x86_64 架构的台式机和笔记本，大小 123 MB，通用性最好。

特殊情况

- **[[Windows on ARM]] 设备**（如 Surface Pro X/9/10、高通处理器笔记本）→ 选 **arm64.exe**，专门为 [[ARM 架构]]优化。
- **其他 .deb / .dmg / .AppImage 版本**→ 给 [[Linux]]、[[macOS]] 用的，Windows 不能用。

确认架构

右键「此电脑」→「属性」→ 看「系统类型」：
- **64 位操作系统, 基于 x64 的处理器** → 选 x64.exe
- **64 位操作系统, 基于 ARM 的处理器** → 选 arm64.exe
