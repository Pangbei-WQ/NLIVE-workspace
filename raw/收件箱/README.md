# 📥 收件箱

使用过程中产生的知识文件都在这里累积，是**原始材料暂存区**。

## 规则

- **谁能写**：只有庞贝本人能往里放文件。
- **AI 只读**：这里面的文件 AI 只能读取，不能修改、改名或删除。
- **发现明显错误**：AI 只能提醒庞贝，由他本人或他明确授权后才可修改。

## 处理流程

AI 每次会话启动时：
1. 扫描本文件夹的新增文件。
2. 将非 `.md` 文件转化为 `.md`（pptx / xmind / 网页剪藏 / PDF 等）。
3. 按文件原标题和内容重新命名。
4. 转化好的 `.md` 移入 `../知识归档/知识档案/`，供后续 wiki 提炼。

> 转化完成的文件即可从收件箱移走；仍在收件箱的 = 还没处理。
