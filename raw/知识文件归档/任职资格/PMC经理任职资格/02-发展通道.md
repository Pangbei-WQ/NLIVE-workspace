# PMC经理 - 发展通道

## 职业发展路径

```
P15 ─── 五级（资深专家/总监）
P14 ─── 五级
P13 ─── 四级（高级经理/专家）    ← 3年
P12 ─── 四级
P11 ─── 四级
P10 ─── 三级（经理/产品经理）    ← 3年
P9  ─── 三级
P8  ─── 三级
P7  ─── 二级                   ← 2年
P6  ─── 二级
P5  ─── 二级
P4  ─── 一级                   ← 1年
P3  ─── 一级
P2  ─── 一级
P1  ─── 一级                   ← 1年
```

## 横向发展通道

- **供应链全链路**：采购 → 生产计划 → 物流 → 关务
- **跨BG轮岗**：PBG、SCBG 等业务群交叉
- **专业转型**：数据分析师、产品经理、运营经理
- **职能转换**：FBP、HRBP、客户采购
