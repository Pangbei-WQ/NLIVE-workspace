# ASTM F963 玩具安全标准（美国市场）

> **状态**：unreviewed
> **最后更新**：2026-09-04
> **来源**：[[raw/知识归档/知识档案/ASTM-F963-2023产品安全标准培训.md]]

## 核心要点

- **ASTM F963-23** 是美国强制性玩具安全标准（经 CPSIA 纳入 16 CFR Part 1250），适用于 ≤14 岁儿童玩具，2023 版取代 F963-17。
- **双支柱**：`CPSIA`（联邦法律，管强制认证/追踪标签/第三方检测）+ `ASTM F963`（技术标准，管具体安全要求与测试方法）。
- 美线出货 **"三件套"缺一不可**：CPSC 认可实验室第三方检测 → CPC 儿童产品证书 → 追踪标签。缺任一：海关不清关 / 平台下架 / 召回+罚款。
- 与 GB 6675 关系：GB 大量参考 ASTM 早期版本但**部分参数更严**（尤其低龄段扭矩/拉力），也有条款 ASTM 更严（纽扣电池、功能锐边年龄线）。
- 涉及品类：毛绒 / 电玩具 / 电动毛绒 / 牙胶 / 摇铃 / 拨浪鼓。

## 关键风险条款（ASTM vs GB 差异）

| 主题 | ASTM 要点 | vs GB 差异要点 |
|------|----------|---------------|
| **年龄分级** | 三档（0–18 / 18–36 / 36–96 月），按 CPSC 指南判定，决定全部测试参数 | 同一产品标「3+」但特征吸引 <3 岁 → 按实际特征重判、按更严测试 → 这是最容易掉的坑 |
| **小零件** | <36 月禁止；试验器 Φ31.7mm | 豁免清单 GB 更多（11 类 vs 6 类） |
| **小球/毛球** | 小球模板 Φ44.5mm；毛球拉脱测试 | 与 GB 完全一致（同源 ISO 8124-1） |
| **端部安全** | 牙胶/摇铃/挤压玩具双模板（A/B）；声响 LCpeak ≤115 dB | 设计启示：端部做 >50mm 或加挡板，避开球形端部 |
| **绳索** | <18 月自由长度 ≤300mm；防缠绕装置 | GB 更细（可缠结绳 ≤220mm、绳径 ≥1.5mm） |
| **重金属** | 涂层铅 ≤90ppm、基材铅 ≤100ppm + 8 元素迁移 | 8 元素一致，GB 多硼(B) |
| **邻苯** | CPSIA 8 种各 ≤0.1% | GB 10 种 → **按 GB 10 种管控即可覆盖美国 8 种** |
| **可燃性** | 毛绒走 A5 蜡烛法 ≤2.5mm/s | GB 走软体填充 ≤30mm/s 或自熄——**测试方法不同** |
| **电气/电池** | 电压 ≤24V DC、电池表面 ≤71°C、禁混用 | GB/T 19865 温升判定不同；防反接 GB 更严 |
| **纽扣电池** | 电池仓须工具打开（M2.0 螺丝等）、滥用后不可触及、本体+包装警告（Reese's Law） | **ASTM 更严**，2023 版重点强化 |
| **磁体/膨胀材料** | 危险磁体不得释放；膨胀材料须够大 | — |

## 可预见性合理滥用（§8）：五项核心测试

模拟儿童摔/拧/拔/压/弯的非预期破坏，顺序不可打乱：

**跌落 → 扭矩 → 拉力 → 压缩 →（弯曲/轮胎拆卸按需）**

ASTM vs GB 核心差异一句话：
- **GB 扭矩/拉力全年龄段一刀切**（0.45 N·m / 70 N）——对 <18 月玩具比 ASTM 严得多（扭矩 2 倍、拉力 +57%）；
- **ASTM 多了翻滚、面部冲击、轮胎拆卸三项补充测试**，覆盖面更广。

| 年龄段 | 跌落 ASTM/GB | 扭矩 ASTM/GB | 拉力 ASTM/GB |
|--------|-------------|-------------|-------------|
| 0–18 月 | 10×137 / 10×138cm | 0.23 / 0.45 N·m | 44.5 / 70 N |
| 18–36 月 | 4×91 / 4×93cm | 0.34 / 0.45 N·m | 66.8 / 70 N |
| 36–96 月 | 4×91 / 4×93cm | 0.45 / 0.45 N·m | 66.8 / 70 N |

## 标识与标签（§5–§7）

- 三个载体：**彩盒/包装、说明书、玩具主体**；追踪标签三要素（制造商+产地至少城市+日期/代码）缺一不可，形式不限（贴标/激光/模印）。
- 安全标签格式：⚠ + `WARNING`（死亡/重伤）或 `CAUTION`（轻伤），信号词高度 ≥1/8 英寸，须在主要显示面板。
- **强制文本**（小零件/小球/弹珠/气球/电池）措辞一个字都不能改；推荐文本可用等效措辞。
- 纽扣电池吞食 2 小时内即可化学灼伤食管（Reese's Law），是 2023 版强化的直接推动力。

## 岗位行动指南（来自培训总结）

1. **设计阶段介入**：包装选材（薄膜）、绳索长度、电池仓（M2.0 螺丝 ≥2 颗/ABS或PC）、声压预测试、端部形状。
2. **索要检测报告**：涂层件 + 基材件分别索要（铅/8 元素）；面料选材阶段燃烧报告 + 邻苯报告一并索要。
3. **来料检验**：填充物供应商报告纳入；拼缝拉力（15 lbf / 67 N）抽检。
4. **跨境出货**：确认实验室为 CPSC 认可、CPC 证书齐备、追踪标签落地（产地须到城市/州）。
