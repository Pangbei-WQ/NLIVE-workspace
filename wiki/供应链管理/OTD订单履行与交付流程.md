# OTD 订单履行与交付流程

> **状态**：unreviewed
> **最后更新**：2026-09-16
> **来源**：[[raw/知识归档/知识档案/OTD订单履行与交付流程手册.md]]（公司流程手册 V2.0，26 页）
> **定位**：这是公司**交付链路的母流程**——一份把"接单到交付"端到端写死到**活动编码**级别的操作手册。本页是它的可检索压缩版，保留了可复用的**口径**（备货推拉结合点、库存分级、缺货管控、指标公式）。

## 核心要点

- **流程范围**：百货、跨境、品牌线**全部业务线**；货架渠道、内容渠道、分销**全部渠道**。
- **20 个流程活动（001–020）** + 3 个外接流程（ITR / IPD / 门店运营），每个活动都有**负责职位 / 详细步骤 / 输入 / 输出**。
- **10 类角色**：SCC 供应链委员会、交付经理（FR）、运营经理、供开经理、**PMC 经理**、客户成功经理、质量经理、库流经理、FBP 经理、效率 BP。
- **两个中枢**：**SCC** 做决策评审（民主集中投票制，**主任一票否决**），**交付经理**做端到端闭环与预测/库存计划。
- **7 个绩效指标**：周转率、滞销率、订单有货率、售后质量率、综合成本利润率、揽收及时率、售罄率。
- **本页最有复用价值的四块**：① 预测协同策略（老品/新品/战役三分法）② 分品类备货推拉结合点（7 类产品各怎么备）③ 库存计划与 ABC 分类口径 ④ 缺货管控与应对路径。
- ⚠️ **对 PMC 最要紧的一句**：手册把 PMC 定义为**承接交付经理的采购计划去执行**（转采购单 → 跟交期 → 协同到货 → 统计供方表现）。**计划源头在交付经理，PMC 是执行承接方** —— 这是认证里讨论"对上级/上游依赖度"时的**事实依据**，不是自我评价。
- ⚠️ 原文件标注「**公司保密文件，谨防外泄**」，入库版已剔除页眉噪声，本页只保留可复用口径。

## 详细内容

### 一、这条流程解决什么问题

**目的**：承接前端需求、拉通后端供应，实现"以客户为中心"的高效交付；同时**平衡交付效率、成本与客户满意度**。

**输入**：来自 DSTE / MM / IPD / IPMS / 1-N / SDM / 新媒体策划和运营 / 门店运营 / 战役活动运作 / LTC / 私域运营 / ITR / 经销商 共 13 条上游流程。
**输出**：26 类表单与手册（需求计划表、供应链策略计划表、战略采购规划、库存计划表、采购清单、供方到货计划表、质量验收报告、库存健康度清单、清库计划表、缺货跟踪表、预测模型、《OTD 订单履行与交付手册》等）。

**关键术语**

| 缩写 | 含义 |
|:----:|------|
| **OTD** | Order to Delivery，订单履行交付流程（端到端：订单处理 → 生产/采购 → 物流 → 库存 → 包装 → 配送 → 收尾确认） |
| **FR** | Fulfillment Responsible，**交付经理** —— 统筹协调、风险管控、资源整合的核心管理角色 |
| **SCC** | Supply Chain Council，**供应链委员会** —— 决策评审机构 |
| **MM / IPD / ITR** | 市场管理流程 / 集成产品开发流程 / 问题到解决流程 |

### 三、四个高频复用口径

#### ① 预测协同策略（活动 003）—— 老品 / 新品 / 战役三分法

> 📌 **原文照录**
> 1. 针对**稳定的老品**，因历史数据对预测的影响权重更大，**交付经理预测为准**，运营经理及市场经理判断为辅。
> 2. 针对**新品**，因参考历史数据进行预测的权重较低，**交付经理的最终预测需要更多结合运营经理及市场经理的判断**。
> 3. 涉及**市场策略及战役波动**影响，交付经理进行最终预测时，须与相关协同方进行**联合判断**。

**分品类的预测分级依据**：按事业部/品类做**分级分类**（品类定位、销量状况、周期特性、异动系数、价格因素、生命周期属性、区域市场特点），再决定用**计划单独预测 / 联合预测 / 销售单独预测**，最优分配协同资源。三条业务线的差异化：**百货**品类庞杂 → 区分品类重点批量计划；**品牌线**高单价定制、组合品多、周期长、供方刚性 → 远期计划 + 主品转单品；**跨境**涉船期规模效应、多供方联动约船期、清关周期与费用、FBA 仓储费 → 定期集中计划。

#### ② 分品类备货推拉结合点（活动 006）

| 品类 | 交期/周期 | 约束 | 备货方式 |
|------|----------|------|---------|
| 大体积注塑类 | < 7 天 | 生产快，但占供方仓储空间 | **按单生产按单交货** |
| 小体积注塑类 | < 7 天 | 不占空间 | **供方现场成品备料** |
| 毛绒布艺 | 45 天 | 布料备料长、手工工序多、排产刚性、成品可堆叠 | **原料 + 成品多个推拉结合点**（供方现场） |
| 电子类 | < 30 天 | 瓶颈在电子原材料、组装工序多、排产刚性、成品体积大 | **原料备料 + 成品订单** |
| 彩盒等包材 | < 20 天 | 排产刚性、材料备料需周期、成品体积大 | **原材料备料 + 成品订单** |
| 木艺类 | < 60 天 | 排产刚性、材料周期、工序多、成本高 | **按单下单生产** |
| 低货值高消耗耗材 | — | 货值低、盘点不划算 | **按起订量双堆（双桶）备货** |

> 📌 原文点睛："PMC 经理须**提前获悉了解供方的生产协同诉求**，结合内部的交货计划进行双方最优方式的协同配合。"
> 这条是**"推拉结合点"谈判的方法论**：不是拍脑袋决定备货方式，而是把「交期 / 供方排产刚性 / 备料周期 / 仓储空间占用 / 货值」五个变量摆开，逐品类算最优切分点。

#### ③ 库存计划与 ABC 分类（活动 007）

**再订货点结构** = 生产周期库存 + 物流周期库存（陆运 + 海运）+ 周末周期库存 + 安全库存（销售波动 + 供方交货风险波动 + 服务水平）。

- 安全库存三来源：**销量波动、供应风险、服务保障水平**；协同时交货率要求 **24 小时 > 95%、48 小时 > 99%**；服务水平**正常水平 > 99.8%**。
- 供应风险不易结构化 → 可**经验性**用交期波动性差值增加库存天数。
- 销量波动性测算须**剥离活动等异常因子**，测波动系数标准差。
- **库存结构** = 安全库存 + 周转库存 + 过剩库存 + 风险库存（超 90 天）+ 滞销库存（无动销）。
- **SKU 有货状态分级**：0 库存 / 缺货 < 5 天 / 5 < 低库存预警 < 15 / 15 < 正常 < 30 / 30 < 过高 < 60 / 60 < 超高 < 90 / 90 < 滞销 / 无动销。
- **分品类库存策略**：百货＝不定时 + 不定量；品牌线＝不定时 + 定量与不定量结合；跨境＝**定时 + 不定量**。
- **ABC 分类**（按日销采购额累积降序）：

| 类 | 累积额 | 订货原则 | 缺货率控制 |
|:--:|:-----:|---------|-----------|
| **A** | 前 80% | 缺货＝紧急重要，须第一时间闭环 | 百货 < 99.9%；跨境东南亚有货率 < 98%；品牌线有货率 < 99.99% |
| **B** | 80–95% | 同上 | 销量缺货率 < 99.8%；跨境东南亚有货率 < 97%；品牌线有货率 < 99.9% |
| **C** | 95–100% | 订货须结合滞销风险，可联合判断是否评估清库 | — |

> 不在比率范围内但基于其他维度重要性的，可**单独标记**纳入相应类别；**组合装分类须考量该 SKU 对关联组合的影响**（如品牌线低货值组件可能关联高价值礼盒）；分类可动态调整。
> 另：**仓库规划**（主仓、云仓、海外仓）由交付经理协同库流经理提前布局；**产品变更**（结构/外观/包装/标签/礼盒组合）由交付经理协同 PMC、库存、质量经理落地（库存消耗、库存终止、供方库存盘点、变更切换、主仓盘点）。

#### ④ 缺货管控与应对（活动 016）

- 日常监控数据：**SKU 缺货率、销量缺货率、订单缺货率、赔付情况**；百货 & 品牌线**以仓库缺货清单即时监控**；订单管理组形成**周缺货汇报复盘机制**并横向同频最佳实践。
- 缺货预警时由**交付经理主导**协同应对：
  1. **区分缺货原因**驱动应对 —— 缩短供方交期 / 临行加急 / 替发 / 次品快速返工 / 紧急启动二供评估 / 客户沟通方案
  2. 库存有限时组织协同沟通，必要时**做不同渠道的库存分配**，**原则上首选保障货架渠道重要链接**
  3. 复盘原因做预防（安全库存设置、供方交期跟踪、质量风险改善）
- 细节参考《**缺货管理办法**》。

**滞销消化手段（活动 016）**：降价促销、联合销售、供方退回、跨渠道消化（分销/跨境/抖音）、易货、线下地摊、减值报损、转客服赠品、转引流赠品。
> 📌 **品牌线特例**：因组品特性与彩盒定制关联，清库须与运营、订单管理组协同，**避免"品清库但盒子闲置"或"盒子清库但品闲置"**；定制库存（半成品、定制包材、芯片机芯）清库须评估供方库存风险，**避免成为库存盲点**。

### 四、绩效指标与口径（7 个）

| 指标 | 公式 | 备注 |
|------|------|------|
| **周转率** | 30 天销售成本 ÷ 30 天平均库存余额 | 库存资金流转速度 |
| **滞销率** | 超 90 天滞销品滞销金额 ÷ 总库存金额 | 积压风险敏感性 |
| **订单有货率** | 可立即发货订单数 ÷ 总订单数 | 响应能力核心指标 |
| **售后质量率** | 1 − 错漏发、质量问题订单数 ÷ 总订单数 | 驱动逆向流程优化 |
| **综合成本利润率** | 供应链全链成品 ÷ 销售额 | 全链路成本控制 |
| **揽收及时率** | 近 30 天揽收超时订单笔数 ÷ 近 30 天应揽收订单笔数 | ⚠️ 定义（≤48 小时占比）与公式方向相反，疑原文笔误 |
| **售罄率**（可选） | 期间销售数量 ÷ 期初库存数量 × 100% | 依交付客户对象而定 |

### 六、PMC 在这条链路里的位置 ⭐

| 维度 | PMC 经理在手册中被写定的事实 |
|------|---------------------------|
| **计划源头** | **不是 PMC** —— 需求计划、库存计划、预测模型均由**交付经理**主导（活动 003 / 007） |
| **PMC 的动作起点** | "**根据交付经理的计划**，转化采购单"（第 5 节 · PMC 经理职责第 1 条） |
| **PMC 独立负责的活动** | **活动 009 供方生产及库流执行**（PMC 为负责职位，唯一一个） |
| **PMC 参与的活动** | 活动 005 战略采购（**执行方**，规划由 PMC 与供开协作）、活动 008 采购执行（与供开经理共同负责） |
| **PMC 的输出** | 供方到货计划表、送货单、采购清单、战略采购规划，以及准时交付率/合格率数据 |
| **PMC 的协同对象** | 交付经理（计划来源）、供开部（价格与供方）、仓储管理部（收货）、质量部（验货异常）、财务（付款与票据） |
